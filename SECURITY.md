# Security Policy

## Supported versions

Security fixes target the latest tagged release. Users should update before
reporting behavior already corrected in a newer release.

## Reporting

Do not publish API keys, private keys, workflow secrets, signed requests, or
exploitable vulnerability details in a GitHub issue. Use the private security
reporting feature on this repository when available, or the private support
channel identified at <https://imprintai.link>.

Reports should include the affected version, impact, minimal reproduction, and
whether any credential may have been exposed. Revoke a compromised ImprintAI
API key immediately.

## Scope

This repository covers the ComfyUI client package. Hosted API, account,
payment, blockchain-provider, and signing-service incidents may require action
by the ImprintAI service operator.
